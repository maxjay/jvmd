# Persistence and incremental semantic architecture: implementation status

This records how the *JVMD Persistence and Incremental Semantic Architecture* baseline is implemented, what was
measured, and which definition-of-done items remain open. Section numbers (§) refer to that document. Measured
results live in [`docs/evidence/`](evidence/); each file is regenerated by the benchmark named in it.

## What was built, phase by phase

| Phase | Implementation | Evidence |
|---|---|---|
| 1. Result identities | `ProofEvaluation.resultIdentity` is the semantic result; `certificateIdentity()` is the proof. Recomputation is explicit: `Evaluated`, `Deferred` (owner recomputes on read), `Unavailable`. The `unavailableProofIdentity` sentinel and the `<unavailable>`/`<unknown>` digests are gone. Leaf identities are `Optional<Hash256>`, and namespace lookups use the three-valued `SemanticKnowledge`. | `ProofDagOrderingTest`, `SemanticProofDagTest`, `SourceProofMutationIntegrationTest` |
| 2. Ordered propagation | `ProofDag` schedules by height. Dependencies discovered during recomputation re-establish heights and re-queue the consumer above a pending producer. Retired consumers retire their downstream. | Full §24 matrix plus 200 random DAGs that converge to from-scratch results with at most one recomputation per consumer |
| 3. File observations | `FileObservationJournal` (CRC32C, append-only, atomic compaction) attached to `FileStateRegistry`. Stamp equality is required, racy observations are rehashed, and providers without ctime/inode always hash. | `FileStatePersistenceTest`; [restart baseline](evidence/restart-baseline.md): 148 MB hashed cold, 0 bytes on warm restart |
| 4. LOCAL memo store | `SemanticMemoStore`: static key, certificate, coverage, completeness, PRESENT/ABSENT result and a SHA-256 integrity trailer. Every record is independently valid, and bounded variants are kept per static key. | `SemanticMemoStoreTest` |
| 5. S0 memo | `SourceNamespaces` is keyed by content, parser version and language mode. Package-scoped `symbol.overview` skips units whose COMPLETE S0 package differs. | `SourceNamespaceMemoTest` (restart, branch switch, worktree, relocation) |
| 6. Restart-stable keys | `PersistableProofKeys` is the executable audit (below). `ResidentSemanticState.stableHierarchyIdentity` is derived beneath the runtime fence. | `SemanticMemoStoreTest`, `RestartStableIdentityTest` |
| 7. Logical classpath slots | `ClasspathSlots` keys, with `ClasspathSequence.Entry.location` as metadata. `ClasspathSearchProof.winnerArtifactKey` is logical and `winnerLocation` is physical. Sequences and searches are built per `IndexStore.ClasspathContext`. | `RestartStableIdentityTest`, `ClasspathSearchProofIntegrationTest`, `ClasspathLifecycleIntegrationTest` |
| 8. Attributed LOCAL memos | Diagnostics plus detached contribution, with a static key binding logical source, content, release, options, javac/platform content, logical classpath sequence and logical roots. The certificate is the transitive content closure (or source-roots content when unproven) plus an S0 namespace leaf. Path options and annotation processors are refused. | `AttributedMemoIntegrationTest`; restart baseline: 160/160 units restored, 0 javac |
| 9. READY gating | READY means storage open and persisted inventory restored. The repository scan runs in the background, and index-tier answers carry `index_reconciling` until it finishes. `jvmd.ready.awaitRepositoryScan=true` restores strict gating. | `ReadinessGatingTest`, `DaemonIndexReadinessTest` |
| 10. Restart baseline | In-process attribution harness (§115). The end-to-end LSP "restart → first correct completion" on the pinned Maven fixture is the `benchmarks/` lifecycle run by `jvmd-benchmarks.yml`. | [restart-baseline.md](evidence/restart-baseline.md) |
| 11. Native MACHINE POC | `segment.MachineSegment`: sealed, mmap'd through `MemorySegment`, no block cache, crash-safe publication. | `MachineSegmentTest`, [machine-storage.md](evidence/machine-storage.md) |
| 12. Accelerators | `segment.MachineAccelerators` is a separate file bound to the base semantic and physical identity. It holds a membership filter, trigram postings, reverse CSR and a large-owner list. Invalid or missing accelerators answer UNKNOWN and fall back. | Same as Phase 11 |
| 13. Routing | `ClasspathRouting`: left-biased union monoid, flat fold, bound per-artifact filters | `ClasspathRoutingTest`, [classpath-routing.md](evidence/classpath-routing.md) |
| 14. Stratification research | S0 vs javac enter differential over the repository's own sources | [stratification.md](evidence/stratification.md): 153/153 equal, S0 4.3× cheaper |
| 15. Impact API | `Analyzer.impact` / `semantic.impact`: proposed unit attributed against an overlay, hypothetical delta and leaves, then a non-mutating `ProofDag.impact` dry run | `SemanticImpactTest` |

Run the benchmark harnesses with
`mvn -pl jvmd-tests test -DexcludedGroups=corpus -Dtest='MachineStorageBenchmark,ClasspathRoutingBenchmark,RestartBaselineBenchmark'`.
They are tagged `benchmark` and excluded from the default build.

## Proof-domain audit (Phase 6)

Persisted certificates accept only keys that `PersistableProofKeys` classifies as logical and restart-stable.
Identities written into a certificate must come from a restart-stable resolver.

| Domain | Persistable keys | Rejected (runtime only) |
|---|---|---|
| EXACT_SYMBOL | SCIP `maven g/a v descriptor` | `local <path-hash>_…` (path-derived), `derived:` |
| MEMBER_RANGE, OVERLOAD_GROUP | persistable owner + name | non-persistable owners |
| HIERARCHY | canonical type SCIP (stable identity beneath the fence) | `document:` keys |
| NAMESPACE | `type:<binary>`, `plan:<simple>`, `source-roots:<gav\|scope>` | `visible` (live namespace fingerprint) |
| NEGATIVE_RESOLUTION | `simple@binary` | — |
| RESOLUTION_PATH | `type:<binary>`, `logical-source:<gav\|role\|path>`, `source-roots-content:<gav\|scope>` | `source:<absolute path>` |
| CLASSPATH_SEARCH | `binary:<name>` (logical winner) | `workspace:<session>`, `compiler` |
| DOCUMENT_SCOPE, RECEIVER, ACCESSIBILITY, WORKSPACE | none | all (document or session addressed) |

Findings:

- The resident `HIERARCHY` identity folds in the process-local `uncertaintyGeneration`. It is now runtime-only, and
  the stable identity is UNKNOWN while any contributing unit is fenced.
- `ClasspathSearchProof.winnerArtifactKey` and `ClasspathSequence` keys were absolute paths. They are now logical
  slots.
- Persisted diagnostic snapshots were already keyed by `(file, hash, context generation, broad compiler stamp)`. The
  precise stamp that carries the uncertainty generation only keys the in-memory entry. No change was needed.

## MACHINE storage decision

**Keep RocksDB.** Native MACHINE storage is not adopted now. From [machine-storage.md](evidence/machine-storage.md), on
26 real jars (100,048 symbols):

- Native wins the range-shaped queries:
  - member prefix: 3.8 vs 16.5 µs p50
  - full-range identity: 5.1 vs 20.7 µs
  - substring: 62 vs 2,423 µs
  - incoming relationships with reverse CSR: 23 vs 31 µs
  - build throughput: 2.3×
  - query allocation: 4.4× lower
- RocksDB wins exact lookup (11 vs 17 µs p50, both decoding a full record) and on-disk size: 54 MB vs 111 MB raw. The
  native files compress to 11.7 MB with 64 KiB deflate blocks, so size is a missing compression layer rather than a
  layout problem.
- The restart baseline shows restart cost was dominated by rehashing and lost memo state. Repairing those (Phases 3–9)
  took a warm restart of a 160-unit module from 9.1 s to 1.3 s with zero javac work, independent of the MACHINE
  backend (§96).

Adopting native storage would need a block-compressed string section and an end-to-end daemon benchmark in which
MACHINE range queries are a measurable share of editor latency. The POC, its tests and the harness stay in the tree
so that comparison can be rerun.

## Definition of done (§119)

- [x] Semantic result identities replace proof identities where required.
- [x] ProofDag execution obeys dynamic dependency ordering.
- [x] Unequal-path graphs do not cause unnecessary repeated recomputation.
- [x] UNKNOWN / ABSENT / PRESENT remain distinct across persistence.
- [x] UNKNOWN has no reusable persisted semantic identity.
- [x] No persisted certificate contains unavailable/UNKNOWN evidence.
- [x] Completeness survives persistence exactly.
- [x] FileStateRegistry observations survive restart safely.
- [x] Racy timestamp cases rehash conservatively.
- [x] Unchanged files avoid unnecessary rehashing.
- [x] Generic static-key + dynamic-certificate LOCAL memos exist.
- [x] In-process proof coverage and persistence coverage are explicitly separated.
- [x] Static memo keys bind classpath, options, platform, processors and other ambient inputs where required. Contexts
  with processors or path options are refused rather than bound.
- [x] Persisted dependency identities are restart-stable and path-independent.
- [x] Runtime fencing generations remain runtime-only unless durably anchored.
- [x] S0 memo reuse works across compatible branches/worktrees/checkouts.
- [x] Attributed LOCAL memos reuse through dynamic dependency validation.
- [x] LOCAL entries are independently valid.
- [x] LOCAL roots/maps are management metadata only.
- [x] UNKNOWN semantic results are never memoized.
- [x] PARTIAL results never return as COMPLETE after restart.
- [x] READY no longer waits for unrelated global repository work where unnecessary.
- [ ] New restart → first-correct-completion baseline is captured before MACHINE replacement. The in-process
  attribution is captured. The LSP completion number on the pinned Maven fixture comes from the CI benchmark lifecycle
  and was not measurable in this environment (no jlink image, no Unix sockets).
- [x] MACHINE semantic projections are separate from physical identities.
- [x] Documentation changes do not churn resolution-only identities.
- [x] MACHINE classpath-dependent references remain symbolic.
- [x] Owner offsets are implemented/measured.
- [x] Whole-owner aggregates are implemented/measured (native segment; RocksDB keeps its cached range identity).
- [x] Prefix proof identities always cover the complete prefix range, not merely returned results.
- [x] Large-owner checkpoints are added only when measurements justify them (not justified).
- [x] Exact lookup alternatives are benchmarked.
- [x] Substring search behaviour remains supported.
- [x] Reverse relationship acceleration is justified or rejected empirically (justified as an accelerator).
- [x] ClasspathContext is explicit per module/source-set/release.
- [x] ClasspathSequence entries use logical slot identities, not physical paths.
- [x] ClasspathSearchProof winner identity uses the same logical slot model.
- [x] ClasspathSequence reconstruction from ordered entries is measured.
- [x] Flat classpath routing fold is measured as baseline.
- [x] Filter/tree/adaptive routing alternatives are measured before adoption (none adopted).
- [x] Confluence tests cover random fact admission ordering/partitioning.
- [x] Epoch is excluded from semantic confluence requirements.
- [x] Native minimal MACHINE facts are measured independently of accelerators.
- [x] Native MACHINE is compared against RocksDB only after restart work has landed.
- [x] Missing/corrupt accelerators only cause fallback/rebuild.
- [x] Corrupt canonical semantic state causes safe cache invalidation/rebuild (segments, memo records, journal).

- [x] Heap, RSS, mapped bytes and page faults are reported separately.
- [x] Final storage decision is evidence-backed: **KEEP ROCKSDB** (for now; conditions above).

## Known limits and follow-ups

- Attributed memos need logical source roots: module coordinates for every root and an indexed logical classpath.
  Modules whose classpath contains unindexed reactor output directories are refused (`classpath-unproven`) and use
  the existing snapshot path.
- Certificate validation snapshots the source roots for each restored unit, which is O(files) stats per unit. A
  snapshot shared within one observation epoch would amortise it.
- Directory inventory persistence (§94) is not implemented; restart still enumerates source directories (18
  enumerations for the 160-unit module).
- File observations are path-keyed physical evidence, so a relocated checkout rehashes once. LOCAL memos still hit
  through logical identities.
